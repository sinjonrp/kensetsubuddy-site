# kensetsubuddy-site

けんせつバディ公式サイト（GitHub Pages公開用）。

- **正本**: `sinjonrp/KensetsuBuddy` リポジトリの `site/` ディレクトリ。本リポジトリはそのコピーを配信する
- **配信元**: `gh-pages` ブランチ（GitHub Pagesの自動有効化を利用。Settings操作不要）
- **公開URL**: https://sinjonrp.github.io/kensetsubuddy-site/
- **更新手順**: KensetsuBuddy 側の `site/` を更新（PR経由）→ 本リポジトリの `main` にPRで取り込み → 同じ内容を `gh-pages` ブランチへ push（直接pushでよい）
